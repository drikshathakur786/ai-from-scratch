# ai-from-scratch

Learning AI and GenAI from the basics, one topic at a time, with a small
experiment for each. Written in my own words, mainly for interview prep.

## Roadmap
- [ ] 01 Tokens and context windows
- [ ] 02 Embeddings
- [ ] 03 Attention and the transformer
- [ ] 04 Prompting and structured outputs
- [ ] 05 Hallucinations and evaluation
- [ ] 06 RAG (vector search, chunking)
- [ ] 07 Fine-tuning vs RAG
- [ ] 08 Agents and tool use
- [ ] 09 Capstone: a deployed LLM app

## How each topic is organised
- `notes.md`: the concept in my own words, plus interview questions
- code: a small experiment that shows the idea working
