# ai-from-scratch

Learning AI and GenAI from the basics, one topic at a time, with a small
experiment for each. Written in my own words, mainly for interview prep.

## Roadmap

| Step | Topic | What I'll know after |
|---|---|---|
| 1 | The big picture: AI, ML, deep learning, GenAI, what an LLM is | The vocabulary, and how the terms nest |
| 2 | ML basics: model, training vs. inference, overfitting, evaluating a model | What "learning from data" means |
| 3 | Neural networks: neuron, weights, loss, gradient descent (intuition) | What's inside every LLM |
| 4 | Tokens and embeddings | How text becomes numbers |
| 5 | Attention and the transformer: context window, temperature | How an LLM produces an answer |
| 6 | Using LLMs: API calls, prompting, structured outputs, hallucinations | Building with LLMs properly |
| 7 | RAG: chunking, vector search, evaluation | The most-asked practical topic |
| 8 | Fine-tuning vs. RAG, agents and tool use, cost, safety | Choosing the right technique |
| 9 | Capstone: a deployed app, plus a mini transformer | Proof for my resume and interviews |
